## Application rules
- Keep home design selection in a shared React provider, initialized after hydration; the header selector and home composition must share one state without changing public URLs.
- Home variants reuse the same content and original imported HTML; change layout and section order instead of duplicating or rewriting indexed content.
- Label illustrative imagery as illustrative until authentic studio photography replaces it.
